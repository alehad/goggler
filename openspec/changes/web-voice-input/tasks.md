The security-review skill found one real MEDIUM finding — not in the voice feature itself, but in the `.claude/settings.json` curl allowlist patterns added the prior session (`fewer-permission-prompts` skill): a wildcard like `Bash(curl * https://goggler.tailde35d2.ts.net*)` matches on raw command text, not a parsed URL, so `https://goggler.tailde35d2.ts.net@attacker.example/...` would satisfy the pattern while curl actually connects to `attacker.example` (URL userinfo confusion) — a theoretical bypass reachable only via prompt injection against the agent itself, not the app's own users. Fixed by requiring an explicit `/` or end-of-string boundary immediately after each hostname instead of an unconstrained wildcard (applied to all three affected patterns: the tailnet, ngrok, and localhost:3000 entries). Copilot CLI's independent review passed with no blocking findings.
